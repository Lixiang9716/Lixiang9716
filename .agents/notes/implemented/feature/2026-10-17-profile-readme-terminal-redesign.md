# Agent Note: Profile README redesigned as a live terminal session

Status: implemented

## Problem

The profile README was a conventional template: emoji header, a badge
fragment line (job / school / location joined by middle dots), a projects
table, and two auto-generated stat blocks. Nothing on the page expressed the
owner's request that the profile read as a "tech otaku" page — personal,
playful, and data-driven — and the identity line used exactly the generic
layout every generated profile uses. The owner asked for a redesign where
data is expressed with animated graphics wherever the platform allows.

## Decision

The page is now framed as one running machine, in the repo's existing
tokyonight palette (matching the daily auto-generated stat cards):

- `assets/hero-terminal.svg` (and `.zh.svg`): a self-typing terminal window
  (SMIL animations, committed SVG — the same mechanism as the contribution
  snake). Identity, uptime (account age, repos), stack, and current mission
  are delivered as diegetic shell output; the badge fragment line is gone.
  Hand-built numbers are a snapshot of real data, regenerated by
  `scripts/generate-profile-svgs.py` (committed) when they drift.
- `assets/telemetry.svg` (and `.zh.svg`): a three-panel strip visualizing
  real hourly-commit data as a 24 h clock (peak 18:00, midnight spike, pink
  pulse on the peak), a system-uptime panel, and a "sleep monitor" gag built
  on the genuine 06:00–07:00 zero-commit window.
- Sections renamed to game/OS vocabulary (Now running / Quest log /
  Telemetry; 正在运行 / 攻略记录 / 遥测数据), the snake framed as a bonus
  stage, footer ends with a `CONTINUE?` countdown. Stats cards and snake
  workflows are unchanged.
- `scripts/generate-profile-svgs.py` is committed so the snapshot numbers
  (uptime years, repo count, hourly shape) can be refreshed by re-running it.

Motion budget: one looping typewriter session (the hero), plus slow ambient
loops in the telemetry strip (60 s clock sweep, 2–3 s pulses). All animation
is declarative SMIL inside SVG, which GitHub serves and plays for `<img>`
embeds; no JavaScript, no external hosts.

## Alternatives considered

- **Third-party animated services** (github-readme-streak-stats, quote
  widgets, profile-view counters) — rejected: the repo already standardized
  on self-hosted, Actions-generated SVGs after the public instances kept
  503-ing (see 2026-09-05-self-hosted-stats-cards.md); these would reintroduce
  that failure mode.
- **Hacker-green CRT palette** (near-black + acid green) — rejected as the
  default "terminal aesthetic" every generated page reaches for; anchoring on
  the repo's existing tokyonight tokens keeps the custom SVGs visually
  continuous with the auto-generated cards.
- **8-bit pixel-game styling** — rejected: harder to keep legible for
  recruiters, and the game framing already lands through vocabulary, the
  snake, and the CONTINUE sign-off.

## Consequences

Known platform limits, accepted: SVG-as-`<img>` cannot load web fonts
(system monospace stack instead) and cannot reliably honor
`prefers-reduced-motion` (SMIL ignores it), so the loops were kept slow and
text-reveal shaped. Snapshot numbers go stale until the generator is re-run;
the committed script is the refresh path.
