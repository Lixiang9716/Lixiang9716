# Agent Note: Profile v2 — neon hero, text stripped to contact and highlights

Status: implemented

## Problem

Owner feedback on the v1 terminal profile: make it cooler and cut the text
down to essential contact info and highlights; free rein to recombine the
material.

## Decision

The page is now almost wordless:

- The hero terminal is replaced by a poster hero (`assets/hero-terminal*.svg`,
  regenerated by the same committed script): katakana matrix rain, glowing
  李响 with a neon-flicker loop, chromatic-glitch LIXIANG9716, one typed
  tagline per cycle, scanlines and HUD corners. The identity and mission that
  v1 spread across four shell commands now compress into the poster; the
  `~/lixiang9716` and `[v8.3 beta]` chips carry the remaining flavor.
- Prose sections are deleted: "Now running" bullets, project descriptions,
  and all four text-heavy stat cards (the 24 h commit clock, uptime and sleep
  panels already tell that story with motion). What remains: a four-row
  quest-log table (project + one tag), the telemetry strip, the snake, one
  telemetry caption, and the contact line.
- Bilingual pair updated in lockstep; telemetry/snake workflows untouched.

## Alternatives considered

- **Keep the stat cards** — real auto-refreshing data, but they are the
  wordiest elements on the page and duplicate the telemetry story; cut for
  the minimal brief.
- **Pixel-art avatar / animated project cards in SVG** — SVG links are not
  clickable inside `<img>` embeds, so project navigation must stay in
  markdown; kept the table.
- **More taglines (stack, location, research)** — every extra line trades
  away the minimal brief; the rain and telemetry already carry the otaku
  identity.
